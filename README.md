# Break-Even Balance

An interactive balance scale that helps students understand linear cost and revenue problems.

The left pan holds the cost (a fixed fee plus a cost per item). The right pan holds the revenue (price per item). Students change the number of items sold until the scale balances. That balance point is the break-even point, where cost equals revenue.

## What's on the page

- **Balance scale** that tips toward the heavier side, with a slider, ±1 / ±10 buttons, and a number box
- **Live numbers** for cost, revenue, and profit, with the expression written out
- **Graph** of the cost and revenue lines; the break-even point is marked once students find it
- **Algebra steps** (hidden until opened) that connect each equation move to the scale
- **Problems:** Newsletter ($1.50/copy + $450 fee, sells for $3 → 300 copies), T-shirts (→ 25), Bake sale (→ 48), or make your own

## How to use

Open `index.html` in any web browser. No installation needed.
